# Todo Tracker

A small, dependency-free todo tracker. Pure HTML/CSS/JS running entirely in the browser — no server, no build step. Todos are saved in the browser's `localStorage`.

## Run it

Just open `index.html` in a browser. That's it.

## Features

- Add a todo
- Mark a todo done/undone
- Delete a todo

Data persists per-browser via `localStorage` (key: `todos`).
