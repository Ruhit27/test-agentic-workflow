# Todo Tracker

A small, dependency-free site. Pure HTML/CSS/JS running entirely in the browser — no server, no build step.

## Run it

Just open `index.html` in a browser. That's it.

## Pages

- **`index.html`** — the todo tracker. Add, complete, and delete todos. Data persists per-browser via `localStorage` (key: `todos`).
- **`snake.html`** — a Nokia-style snake game, linked from the todo page. Arrow keys move, space restarts after game over.

## Features

- Add a todo
- Mark a todo done/undone
- Delete a todo
- Play a classic snake game
